файл eng_web2.txt взят из https://github.com/mwiens91/english-words-py/tree/master/raw_data

Данная программа создана для удаления слишком много несуществующих (или не актуальных) слов, такие как «aba», «aa» и много других из eng_web2.txt.
А также добавления реальных нехватающих трехбуквенных слов. И шаблонов.

Как работает?
Добавляете либо перевод либо просто слово в eng_слова_из_трех_букв.txt
Также шаблоны такие как "abc" "123" и другие в eng_слова_из_трех_букв.txt

Далее программа возьмет слова длины от 3 до 10 букв из eng_web2.txt
вставит в new_new.txt 
Далее добавит в в конец файла new_new.txt слова из eng_слова_из_трех_букв.txt
